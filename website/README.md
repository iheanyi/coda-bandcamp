# Coda landing page

The official landing page for
[Coda](https://github.com/iheanyi/coda-bandcamp), a fast, open-source desktop
player for Bandcamp collections.

## Local development

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Create the production build with:

```bash
npm run build
```

The page is built with vinext, React, TypeScript, and Tailwind CSS, and is
deployed through OpenAI Sites.
